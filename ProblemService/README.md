## step to setup the starter template

1. Clone the project

```
git clone https://github.com/VivekKumarDwivedi/Express-TypeScript-Starter-Project.git <project name>
```

2. Move in the folder structure

```
cd <project name>
```
3. Install npm dependencies

```
npm i
```
4. Create the .env file in the root directory and add the 'PORT' env variable

```
echo PORT=3000 >> .env
```

5. Start the express server 

```
npm run dev
```
